# Audio Assets Directory

Place your audio files here to customize the sounds:

- `happy-birthday-asghar-khoso.mp3` - Background song (Asghar Khoso — Happy Birthday)
- `happy-birthday-celebration.mp3` - Grand celebration sound effect
- `click.mp3` - Soft UI click sound
- `pop.mp3` - Soft bubble pop on option selection
- `success.mp3` - Soft match / sparkle sound

Note: If any file is missing, the app continues to operate smoothly using synthesized Web Audio chimes without errors.
